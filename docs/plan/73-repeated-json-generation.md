### 现有契约与尚未确认的根因

- [客户端传输](../../src/dictation/transport.rs)只将 delta 用于临时预览；匹配的成功 `response.done`、单输出单文本及 `output_text.done` 一致后才解析并交付。超时为 90 秒，增量总量上限为 64 KiB。
- [最终结果解析](../../src/dictation/result.rs)已能读取第一个完整对象及完整外层 JSON 围栏。这发生在成功完成之后，不能让未完成的流正常结束。
- [引擎](../../src/dictation/engine.rs)失败不交付、不学习、不自动重放已提交音频；[既有测试](../../src/dictation/engine/tests.rs)允许临时正文被最终结果纠正，并拒绝 incomplete、cancelled 或不一致的最终结果。
- 本机相邻 `gemmae4b-server` 的 `qwen_lm.stream_text` 使用贪心采样；本机 MLX-LM 0.32.0 依赖 `tokenizer.eos_token_ids` 停止，服务消费生成器完毕后才发送完成事件。这些仅是本地源码事实，尚未核对线上部署。

缺少线上代码版本、实际权重/config/tokenizer 身份、失败请求使用的 EOS 集合和生成 token ID。当前不认定“EOS 配置错误”或“贪心采样必然导致循环”。模型、tokenizer 和服务实际行为需要核对；不得用本地代码代替线上证据。

### 拟议行为与最小改动边界

目标是三个已知默认循环场景自然停止，生成单个对象并正常完成；长句、完整模型名称和口述中的两次“腾讯”保持完整。成功交付边界、默认 prompt 顺序、个人配置、词库和记忆均不变。

先核对实际部署与模型配置。若确认 EOS 集合或加载错误，在服务所属的 tokenizer 加载／生成入口修正；若实际未生成 EOS，记录证据后再针对解码或输入原因拟定一个候选，不预先指定重复惩罚或温度。不能用参数碰运气代替因果验证。

现阶段不新增产品接口、配置项或客户端状态。保留 `stream_text(thinker, tokenizer, prompt, *, max_tokens, prompt_cache=None)` 和客户端解析／交付接口。根因确认后在本记录补充确切文件、改动和测试；涉及成功语义、接口扩展或跨模块重构时重新确认，不用本计划笼统授权未知实现。

客户端发现第二个顶层对象后快速失败可以减少等待，但它只属于止损。本计划不默认实施该行为，也不将正常 JSON 字符串里的花括号、正文重复词或重复专名当作循环。提前取首对象、缩短超时、降低 token 预算均不作为根治方案。
